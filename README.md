## Возможности

- **Два режима работы с быстрым переключением в один клик:**
  - **Войс-мод (Voice Studio):** голосовые карточки-пресеты, аналоговые крутилки точной настройки (питч, овердрайв, бас, роботизация), уровни входа и выхода.
  - **Саундпад (Soundpad):** полноэкранная таблица сэмплов, последовательное добавление без фиксированного лимита, drag-and-drop аудиофайлов из Проводника, нижняя консоль воспроизведения и мониторинга.

- **Аналоговые крутилки Rotary Knobs:**
  - Гибридная физика: поддержка естественного кругового вращения циферблата и линейного вертикального перетаскивания (стандарт FL Studio / Ableton / FabFilter / Voicemod).
  - Мгновенный клик по светящейся дуге циферблата для точной установки значения.
  - Поддержка колесика мыши и микро-подстройки с зажатым Shift.
  - Двойной клик для сброса в значение по умолчанию.

- **Динамический саундпад:**
  - Последовательное добавление звуков один за другим без жесткого лимита в 12 слотов.
  - Мульти-выбор файлов (.mp3, .wav, .ogg, .flac) через диалог или прямое перетаскивание пачки файлов мышью.
  - Горячие клавиши F1–F12, пробел для запуска выбранного сэмпла, Delete для удаления, Esc для остановки всех звуков.
  - Независимая полифония и регулировка общей громкости сэмплов.

- **5 голосовых пресетов DSP:**
  - 1. Аноним: многослойный сдвиг тона (-7.0 и -13.5 полутонов), глубокий резонанс (135 Гц), срез верхов (3900 Гц) и ламповый перегруз.
  - 2. Женский: формантный сдвиг (+3.8 полутона), фильтр баса (170 Гц), осветление гармоник (2800 Гц).
  - 3. Ребенок: звонкий голос (+6.0 полутонов), обрезной фильтр 230 Гц, акцент 3600 Гц.
  - 4. Демон: экстремально низкий рык (-9.0 и -15.5 полутонов) с массивным овердрайвом.
  - 5. Пользовательский: свободная настройка крутилками (питч -18..+18 st, дисторшн 0..100%, бас 0..+15 дБ, роботизация 0..100%).

- **Премиальный True Black (OLED) дизайн:**
  - Глубокий черный фон, изумрудные акценты, векторные монохромные пиктограммы без эмодзи.
  - Полная поддержка двух языков интерфейса (Русский и English).

- **Аудио-маршрутизация:**
  - Вывод в любой виртуальный кабель (VB-CABLE, Animaze, Voicemod) → Discord, Telegram, CS2, Dota 2, OBS.
  - Мониторинг себя в наушниках с отдельной цепочкой вывода.
  - Настройки сохраняются в `%APPDATA%\OpenSoundPad\config.json`.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `1`–`5` | Пресеты голоса в Войс-моде |
| `F1`–`F12` | Быстрый запуск сэмплов |
| `Space` | Воспроизвести выбранный сэмпл |
| `Esc` | Стоп всех сэмплов |
| `Delete` | Удалить выбранный сэмпл из саундпада |
| `T` | Вкл/выкл голосовой эффект (Bypass) |
| `M` | Заглушить микрофон (Mute) |
| `L` | Мониторинг в наушниках (Listen) |

## Требования

- Windows 10 / 11, .NET 9 Runtime (для self-contained сборки не требуется)
- Виртуальный аудиодрайвер: VB-Audio Virtual Cable, Animaze или Voicemod

---

## Запуск из исходников

```bash
cd src/OpenSoundPad
dotnet run
```

## Сборка релиза (один exe)

```bash
dotnet publish src/OpenSoundPad/OpenSoundPad.csproj -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o publish
```

## Настройка виртуального микрофона

1. В верхней панели нажмите «Устройства» или в настройках выберите микрофон, виртуальный кабель и наушники, затем нажмите «Старт».
2. В Discord / Telegram / играх в поле «Устройство ввода» выберите соответствующий виртуальный микрофон (`CABLE Output`, `Microphone (Animaze Virtual Audio)`).

## Структура проекта

- `src/OpenSoundPad/` — WPF-приложение (.NET 9, `WinExe`).
- `src/OpenSoundPad/Controls/KnobControl.xaml(.cs)` — аналоговые крутилки параметров с субпиксельной плавностью.
- `src/OpenSoundPad/Audio/OspDsp.cs` — DSP-ядро (гранулярный питч-шифтинг, биквады, овердрайв, гейт, кроссфейд).
- `src/OpenSoundPad/Audio/OspEngine.cs` — WASAPI-движок на NAudio (захват → DSP+пады → кабель + монитор).
- `src/OpenSoundPad/Audio/SoundPadBank.cs` — динамический банк сэмплов с полифонией.
- `src/OpenSoundPad/Audio/OspConfig.cs` — конфигурация с поддержкой списка сэмплов и обратной миграцией.
- `src/OpenSoundPad/MainWindow.xaml(.cs)` — главное окно: переключатель режимов, Войс-мод, Саундпад, микшер.
- `src/OpenSoundPad/SettingsWindow.xaml(.cs)` — окно настроек устройств и языка.
- `driver/OspVirtualMic.inf` — каркас INF для будущего драйвера.
